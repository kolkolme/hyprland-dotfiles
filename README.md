# Рабочий стол Hyprland

Конфиги и утилиты рабочего стола на Hyprland под Kali Linux.
Ставится одним скриптом на чистую систему.

## Установка

Работает на **Kali Linux** и на **Debian 13 (trixie)**.

```bash
git clone <адрес-репозитория> ~/dotfiles
cd ~/dotfiles
./install.sh
```

Скрипт спросит подтверждение, поставит пакеты, разложит конфиги и утилиты,
а в конце сам вызовет `apps.sh` и поставит прикладные программы.
Всё, что он перезапишет, сначала уедет в `~/.dotfiles-backup-<дата>`.

После установки — перезайти в систему, выбрав сессию **Hyprland**.

## Что внутри

| | |
|---|---|
| `config/` | конфиги → `~/.config` |
| `shell/` | `zshrc` → `~/.zshrc` |
| `bin/` | 24 утилиты → `~/.local/bin` |
| `wallpapers/` | три обоины → `~/Pictures/wallpapers` |
| `icons/` | тема курсора → `~/.local/share/icons` |
| `packages.txt` | 64 пакета, которые ставит установщик |
| `apps.sh` | прикладные программы: C++, VS Code, Steam, Telegram, Discord |
| `security-tools.sh` | инструменты безопасности из набора Kali |

### Рабочий стол

Hyprland (83 бинда), Waybar, wofi, kitty, swaync, wlogout, hyprlock, hypridle.
Тема — Catppuccin Mocha, шрифт JetBrains Mono.

### Терминал

**kitty** — шрифт JetBrains Mono 11, прозрачность 0.82 (меняется на лету:
`Ctrl+Shift+A`, затем `M` темнее / `L` светлее), след за курсором, вкладки
powerline, буфер 10000 строк, палитра Catppuccin.

**zsh** (`shell/zshrc`) — приглашение starship, подсветка синтаксиса,
автодополнение по истории, `fzf` на `Ctrl+R` и `Ctrl+T`, `zoxide` (`z` —
прыжок в частую папку).

Алиасы: `ls`/`ll`/`la`/`lt` → `eza` с иконками и git-статусом, `cat` → `bat`.

Функции: `extract <архив>` (любой формат), `vol 50` и `mute` (звук через
wpctl), `update` (обновить систему одной командой), `tg` и `ff` (Telegram и
Firefox, отцепленные от терминала), `vpn`, `wifi`.

**fastfetch** — приветствие при открытии терминала: радужный логотип Arch
(`config/fastfetch/arch-rainbow.txt`) плюс ОС, ядро, WM, аптайм, память,
батарея. Показывается только в первом окне, во вложенных `zsh` — нет.

### Утилиты

Все запускаются из терминала по имени. Многие завязаны на панель Waybar.

**Оболочка рабочего стола**
- `wallpick` — выбор обоев. Генерирует палитру waybar / wofi / kitty из картинки,
  поэтому смена обоев перекрашивает всю систему
- `windows` — переключатель окон в духе App Exposé
- `glass` — прозрачность и «жидкое стекло» для темы
- `snapdrop` — что делать с окном, когда его бросают к краю экрана
- `hypr-help` — шпаргалка по всем горячим клавишам
- `hypr-tty` — запуск Hyprland из текстовой консоли
- `hypr-heartbeat` — пульс Hyprland раз в 5 секунд, для отладки зависаний

**Ежедневное**
- `tasks` — задачник в терминале
- `notes` — заметки в терминале (обычные `.md` в `~/.local/share/notes`)
- `calendar` — календарь-виджет
- `english` — оценка качества английского текста (нужен `aspell`)

**Железо и система**
- `wifi` — менеджер Wi-Fi
- `bt` — менеджер Bluetooth
- `vpn` — VPN через NetworkManager, с кнопкой в Waybar
- `sysmon` — нагрузка CPU/памяти для панели
- `nightmode` — ночной режим экрана через hyprsunset
- `dim` — приглушение экрана по бездействию
- `scroll` — скорость прокрутки тачпада
- `screenshot` — скриншот с превью в уведомлении
- `lock` / `lock-kbd` — блокировка экрана
- `desk` — переключение между Xfce и Hyprland
- `games`, `steam-quit` — игрушки для терминала и корректный выход из Steam

## Debian

Установщик сам определяет дистрибутив и подстраивается.

Из 64 пакетов **57 есть в trixie напрямую**, а весь Hyprland (`hyprland`,
`hypridle`, `hyprlock`, `hyprpaper`, `hyprsunset`, `xdg-desktop-portal-hyprland`)
лежит только в **backports** — скрипт подключает их сам.

Версии сходятся: backports даёт Hyprland 0.55.2, а синтаксис `windowrule`
с префиксом `match:` появился ещё в 0.53, так что конфиг работает без правок.
Остальные компоненты в Debian и Kali одной версии.

Важная тонкость, из-за которой всё чуть не развалилось: на Debian пакеты
ставятся **одной командой с `-t <codename>-backports`**. Если поставить
Hyprland отдельно, он притянет свежий `libxkbcommon0` из backports, а
`waybar` и `pipewire` из main потребуют старый — apt упрётся в
`held broken packages`, и они молча не встанут. Система получится
с Hyprland, но без панели и без звука. С общим `-t` apt подбирает
согласованный набор: что нужно берёт из backports, остальное из main.

Что нужно от тебя: в `/etc/apt/sources.list` должны быть **contrib** и
**non-free**, иначе не поставится Steam и часть прошивок. Скрипт предупредит.

`fonts-nerd-symbols` в стабильном Debian нет — он пропускается, значки в
Waybar берутся из `fonts-font-awesome`.

## Инструменты безопасности (`security-tools.sh`)

Набор в духе Kali: nmap, wireshark, metasploit, sqlmap, hashcat, hydra,
john, aircrack-ng, SecLists и прочее. Установщик спрашивает отдельно —
весит несколько гигабайт.

**На Kali** всё берётся из репозиториев.

**На Debian** 19 инструментов есть в репозиториях, а 10 нет. Они ставятся
из официальных источников самих разработчиков:

| Инструмент | Откуда |
|---|---|
| metasploit-framework | официальный установщик Rapid7 |
| netexec, theHarvester | pipx с GitHub |
| responder, nikto, enum4linux | git clone в `~/.local/opt` |
| exploitdb (searchsploit) | git clone с GitLab |
| wpscan | ruby gem |
| SecLists | git clone, около 1 ГБ |
| Burp Suite | вручную — у PortSwigger лицензия в установщике |

`theHarvester` на Debian 13 не ставится: свежая версия требует Python 3.14,
а в системе 3.13. Скрипт скажет об этом и пойдёт дальше — на работу
остального это не влияет.

Необязательные инструменты не роняют установку. Скрипт завершается ошибкой
только если не встал базовый набор: nmap, sqlmap, hydra, john, hashcat,
aircrack-ng.

**Репозитории Kali к Debian не подключаются.** Kali собрана на базе
Debian testing/sid, и подключение её репозиториев к обычному Debian ломает
систему — об этом предупреждает и сама команда Kali. Поэтому только
официальные источники.

## Установщик проверяет сам себя

В конце каждый скрипт проверяет, что действительно получилось, и при
нехватке чего-то важного **завершается с ошибкой**, а не рапортует успех.

`install.sh` проверяет: `Hyprland`, `waybar`, `kitty`, `wofi`, `hyprlock`,
`hyprpaper`, `wpctl`, `zsh`; конфиги Hyprland и Waybar; утилиты в
`~/.local/bin`; `.zshrc`; файл сессии для экрана входа; настроенный
менеджер входа.

Если чего-то нет, выводится красная рамка со списком и что делать дальше.
Молчаливых неудач больше нет — раньше строчка «не встал: waybar» терялась
в середине вывода, и человек узнавал о поломке, только войдя в систему.

## Прикладные программы (`apps.sh`)

Ставятся автоматически в конце `install.sh`. Можно запустить и отдельно —
уже установленное скрипт пропускает, так что повторный запуск безопасен:

```bash
./apps.sh
```

| Программа | Откуда |
|---|---|
| **g++**, gdb, cmake, make | `build-essential` из репозиториев |
| **VS Code** | репозиторий Microsoft (ключ и `vscode.sources` добавляются скриптом) |
| **Steam** | `steam-installer`; скрипт сам включает архитектуру i386 |
| **Telegram** | tar.xz с telegram.org → `~/.local/opt/Telegram` |
| **Discord** | tar.gz с discord.com → `~/.local/opt/Discord` |

Telegram и Discord ставятся в домашнюю папку, без root. Скрипт создаёт для них
команды в `~/.local/bin` и ярлыки в меню. Discord тянет маленький загрузчик
(2 МБ), остальное докачивает при первом запуске — это нормально.

Свою иконку Telegram прописывает сам при первом запуске, до этого будет
стандартная.

Если что-то не установилось, скрипт скажет что именно и не свалится —
остальное поставится.

## Если в Hyprland не работают мышь и клавиатура

Самая частая поломка. Hyprland не открывает `/dev/input` напрямую — он
просит устройства у `systemd-logind` по D-Bus, а тот отдаёт их только
внутри **активного сеанса на seat**. Нет сеанса — нет ни мыши, ни клавиатуры,
хотя картинка рисуется.

Сеанс создаёт менеджер входа. Проверь:

```bash
systemctl is-enabled sddm        # должно быть enabled
loginctl show-session $XDG_SESSION_ID -p Type -p Active -p Seat
```

Нужно `Seat=seat0`, `Active=yes`, `Type=wayland`. Если не так:

```bash
sudo systemctl enable sddm
sudo systemctl set-default graphical.target
sudo reboot
```

Запускать Hyprland из текстовой консоли вручную (в том числе через
`hypr-tty`) — путь, на котором это чаще всего и ломается. Через экран
входа надёжнее.

После установки нужна именно **перезагрузка**, а не выход из сессии:
членство в группах подхватывается только при новом входе.

## Одна особенность: `vpn` и `wifi` существуют дважды

В `~/.local/bin` лежат полноценные утилиты (`wifi` — 33 КБ, `vpn` — 5.6 КБ),
и одновременно в `.zshrc` объявлены функции с теми же именами.

Функция в zsh перекрывает файл из `PATH`, поэтому:

- набрал `wifi` в терминале → сработает **короткая функция** из `.zshrc`
- Waybar зовёт `~/.local/bin/vpn status` по полному пути → получает **скрипт**

Так было на исходной машине, я оставил как есть. Если хочешь полные версии
в терминале — удали функции `vpn()` и `wifi()` из `~/.zshrc`, либо зови их
как `~/.local/bin/wifi`.

## Личные данные не входят

В репозитории только код и конфиги. Заметки, задачи и прогресс по английскому
установщик создаёт **пустыми**:

- `~/.local/share/notes/`
- `~/.local/share/tasks.json`
- `~/.local/share/english/`

История команд (`~/.zsh_history`) тоже не входит.

## Настроено под конкретный ноутбук — проверь у себя

Часть утилит завязана на железо исходной машины. Ставятся они везде,
но работать будут по-разному:

- **`dim`, `nightmode`** — яркость через `brightnessctl`. На другом экране
  может не подхватиться
- **`vpn`** — заточен под другую сеть. Свой сервер и учётные данные задай сам.
  Без запущенного `nm-applet` (или другого агента секретов) `openconnect`
  молча не подключится
- **`wifi`, `bt`** — сами по себе универсальные, но профили сетей у тебя свои
- **Звук** — если тишина, проверь `alsamixer`. На некоторых ноутбуках
  отдельный ключ громкости глушит сразу и колонки, и наушники
- **Показания батареи** — на части ноутбуков мигают между «от сети» и «от батареи».
  Не делай выводов по одному чтению

## Обои

В комплекте три штуки, пережатые до 2560px. Полный набор — отдельным архивом,
просто распакуй в `~/Pictures/wallpapers` и перезапусти `wallpick`.

## Правка конфигов

Hyprland 0.56+: в `windowrule` первым аргументом идёт `1`.
Одна сломанная строка глушит все бинды ниже неё — после правки всегда
`hyprctl reload` и проверить, что клавиши живы.

Цвета Waybar и wofi генерирует `wallpick` из обоев. Править их руками
в `style.css` смысла мало — при следующей смене обоев перезапишутся.
